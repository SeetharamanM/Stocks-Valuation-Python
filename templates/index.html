Deep Valuation

Screener export in, defensible fair value out — computed entirely in Python

Company

Banks and NBFCs suppress ROCE, EV/EBITDA and capex measures, which do not apply to them.

Data file

Use the “Export to Excel” button on the company's Screener.in page. The workbook must keep its Data Sheet tab and its original row layout — that sheet is the sole source of every financial figure in the report.

Market data — blank fields are fetched automatically

Fetched from Yahoo Finance when left blank. Indian coverage can be patchy — anything it cannot supply is reported as unavailable rather than guessed, so override here when you have better data.

Discount rate inputs

These two are the only inputs the model cannot derive from the spreadsheet. They set the discount rate, which Section 10 of the report shows is the largest single source of valuation error — so they are worth getting right.

Runs in a few seconds. Every figure and every paragraph is computed in Python by stated rules: no API key, no language model, nothing sent anywhere.
